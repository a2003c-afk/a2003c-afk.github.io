개인정보처리방침 (Privacy Policy)

시행일: 2026-10-12

1. 무엇을 하는 앱인가

이 앱은 운영자가 직접 만든 영상을 운영자 본인의 YouTube 채널에 업로드하고 업로드 상태를 확인하는 데에만 사용됩니다. 사용자는 운영자 한 명뿐입니다.

2. 사용하는 Google 데이터

  • YouTube 업로드 권한(youtube.upload): 운영자 채널에 영상 올리기
  • YouTube 읽기 권한(youtube.readonly): 올린 영상의 공개·처리 상태 확인, 채널 이름 표시
  • YouTube 관리 권한(youtube.force-ssl): 운영자가 올린 영상의 제목·설명 수정

이 데이터는 운영자 PC에만 저장되며 제3자에게 판매·공유·전송하지 않습니다. 광고나 분석 목적으로 사용하지 않습니다.

3. 보관과 삭제

로그인 토큰은 운영자 PC에만 보관합니다. Google 계정의 '타사 앱 연결'에서 언제든 접근 권한을 해제할 수 있으며, 해제하면 토큰은 더 이상 사용할 수 없습니다.

4. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 사용하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
